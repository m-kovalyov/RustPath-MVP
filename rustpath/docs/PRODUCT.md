# Product brief

**Рабочее название:** RustPath. **Язык продукта:** русский. **Основной сценарий:** новичок открывает короткий урок, понимает одну идею, правит Rust-код, получает диагностику и открывает следующий уровень.

## Пользовательские требования и покрытие

| Требование | В MVP | Что ещё нужно |
|---|---|---|
| Веб-приложение | Vue SPA + Rust HTTP API | Публичная публикация |
| Frontend Vue | Vue 3, TypeScript, SFC/Composition API | Полный accessibility audit |
| Backend Rust | Axum/Tokio/SQLx, traits и адаптеры | Production hardening |
| Подходящая БД | PostgreSQL, миграции, индексы, транзакции | Managed setup, PITR/restore test |
| Понятность/много уровней | 16 авторских уровней, 4 модуля, hints | UX-тесты новичков, полный курс |
| Классный дизайн | Responsive, светлая/тёмная тема, редактор | Брендинг по результатам UX обратной связи |
| Принципы ООП/паттерны | Encapsulation, traits, composition, Repository/Adapter/DI | Ревью архитектуры при росте |
| До middle | Карта 05–09 + рубрика компетенций | Продвинутый курс, самостоятельные проекты и внешнее ревью |
| Передовые технологии | Поддерживаемый современный стек и lockfiles | Автообновления с тестами и аудитом, не бесконтрольный latest |
| Рабочий продукт | Код API/frontend и сохранение прогресса проверены | Целевой Docker E2E, security/нагрузка перед запуском |

## Формат урока

Одна цель → понятное объяснение → маленький пример → задача → стартовый код → реальные тесты поведения → две подсказки → объяснение compiler feedback → следующий шаг. Учебная сессия 5–15 минут — проектное намерение, а не измеренный UX факт.

## Референсы и самостоятельность

Rustlings — практика маленькими упражнениями. Mainmatter 100 exercises — постепенное learning-by-doing; материалы CC BY-NC не скопированы. Duolingo/Codewars — пользовательские ориентиры короткого прогресса и практики; не заявляется копирование их механик/контента. Coddy/Metanit — ориентиры из запроса, не исследованные как полный набор источников. Нет чужих логотипов/уроков.

## Definition of Done всей платформы

1. Полный маршрут от новичка до продвинутых инженерных задач.
2. Постоянные аккаунты, восстановление/удаление данных и доступ с разных устройств.
3. Sandbox на dedicated execution node с подтверждёнными лимитами и security audit.
4. Реальная проверка целевого Docker deployment, нагрузочный отчёт и мониторинг.
5. Бэкапы с тестом восстановления, секреты, TLS и release process.
6. Самостоятельные проекты, reviewer workflow и прозрачная рубрика оценки.
7. UX-исследования и доступность.

MVP закрывает первую вертикаль, но не все критерии конечного продукта.
