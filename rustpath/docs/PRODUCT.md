# Product brief — RustPath 0.2

Русскоязычная интерактивная платформа: понять одну идею → попробовать → получить обратную связь → закрепить. Не обещает должность middle за прохождение уроков.

## Покрытие

| Требование | Реализовано | Следующие шаги |
|---|---|---|
| Vue frontend / Rust backend | Vue 3 + TypeScript, Axum/Tokio/SQLx | Production-развёртывание |
| Хранение прогресса | PostgreSQL, транзакции, гостевые сессии | Аккаунты, восстановление и синхронизация |
| Начать без опыта | 12 вводных уроков, переменные и функции; 3 квиза | UX-тесты начинающих |
| Основы | 16 исходных уроков сохранены | Больше задач на перенос навыка |
| Продвинутый Rust | 16 уроков: generics, lifetimes, Cow, ошибки, closures, type-state, std threads | Async/Tokio, API/PostgreSQL, эксплуатация |
| Повторение | Закладки на сервере, список пройденного | Интервальное повторение и диагностика пробелов |
| Понятный дизайн | 3 маршрута, поиск, аккордеоны, вкладки, светлая/тёмная тема | Полный accessibility audit |
| Наглядность | 4 шага ownership, деликатная CSS-анимация/перспектива | Визуализация более сложных сценариев |
| ООП и паттерны | Структуры/методы, traits, композиция, Repository/Adapter/DI | Ревью при расширении домена |
| Проверка кода | Приватный runner, Rust unit tests | Подтверждённый E2E 0.2 на целевой инфраструктуре, усиление sandbox |
| Путь к самостоятельной разработке | Измеримые учебные результаты и roadmap | Capstone, внешнее ревью, безопасность, нагрузка |

44 урока / 11 модулей / 3 независимых маршрута. 41 задача с кодом и 3 квиза. Вводные темы не блокируют доступ к уже пройденным основам. Учебная сессия 5–15 минут — проектное намерение, не измеренный UX факт.

## Методика и источники

Понятная цель, короткое объяснение, пример, частая ошибка, практика, постепенные подсказки и материалы. Источники и границы заимствования — `SOURCES.md`: Metanit, The Rust Programming Language, Brown interactive book, Stanford CS110L, Rustlings. Материалы сформулированы заново; проект не связан с университетами и не сертифицирован ими.

Сложность последних упражнений не равна производственному опыту. Для конечного продукта нужны самостоятельные сервисы, async, авторизация/транзакции, наблюдаемость, code review и сопровождение.

## До публичного релиза

Аккаунты, постоянное восстановление доступа, dedicated execution host с усиленной изоляцией, подтверждённые ресурсные лимиты, security/нагрузочное тестирование, TLS/секреты, бэкапы с восстановлением, reviewer workflow и UX-исследования. Текущий Docker socket runner нельзя открывать для публичного недоверенного исполнения без выполнения требований безопасности.
